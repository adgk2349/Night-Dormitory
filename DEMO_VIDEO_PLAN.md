# 3-Minute Demo Video Plan

Target length: 2:30-3:00.

Generated demo video:

https://adgk2349.github.io/Night-Dormitory/demo/night-dormitory-demo.webm

Regenerate locally:

```bash
npm run dev
npm run record:demo
```

The automated capture uses `#showcase` to show the title, story preview, room, bathroom, memory event, corridor/elevator, first-floor rice cooker area, and loop ending within the three-minute limit.

## 0:00-0:15

- Show title screen.
- Click start.
- Let the story preview text appear for a few seconds.

## 0:15-0:45

- Walk through the room slowly.
- Show the rebuilt narrow goshiwon layout: left bed, vertical window with road/exterior facade, wall AC, desk opposite the bed, chair, fan, fluorescent light, and wood/vinyl floor.
- Turn a light switch on/off once.

## 0:45-1:25

- Interact with the bathroom door and briefly show the tiled sink/toilet/shower space.
- Interact with the bedroom/closet door.
- Collect the first memory fragment.
- Show the objective changing and the chair repositioning after the memory fragment.

## 1:25-2:05

- Collect the remaining memory fragments.
- Show the room state shift: darker lighting, changed atmosphere, audio tension.
- Try the entrance door after it unlocks.

## 2:05-2:40

- Enter the corridor.
- Show the room-adjacent elevator, clutter along the corridor wall, flyers, slippers near room 204, and the power strip cable entering the door gap.
- Let the slippers event play after entering the corridor.
- Press the elevator button.
- Move to the first-floor shared rice-cooker area.
- Show the rice-cooker shelf, notice board, plastic table, sink block, and fluorescent light before interacting with the rice cooker.

## 2:40-3:00

- Interact with the rice cooker.
- Show the darker rice-cooker pulse and loop ending.
- End on the title/ending screen.

## Notes

- Record with game audio enabled.
- Keep mouse movement slow to avoid motion sickness.
- Avoid spending more than 10 seconds searching for interactables.
- The video should show actual gameplay, not only menus.
